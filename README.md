# Jest Tutorial Examples

This repository contains various examples demonstrating how to use Jest for testing JavaScript code. Each example is organized in its own directory and includes both the implementation and tests.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run tests:
```bash
npm test
```

## Examples

1. Basic Testing (`examples/01-basic`)
   - Simple function testing
   - Basic assertions
   - Test structure

2. Async Testing (`examples/02-async`)
   - Testing promises
   - Async/await testing
   - Mocking async functions

3. Mocking (`examples/03-mocking`)
   - Function mocking
   - Module mocking
   - Mock implementations

4. Snapshot Testing (`examples/04-snapshots`)
   - Component snapshot testing
   - Snapshot updates
   - Snapshot best practices

5. Integration Testing (`examples/05-integration`)
   - Testing multiple components
   - API integration testing
   - Database integration
